# React Bits Design Direction

React Bits is a copy-paste collection of customizable React component source rather than a runtime dependency. The selected OceanEmbed direction uses a restrained subset of its patterns: a low-motion radar/line-wave field for spatial context, signal-line entrance treatment for major data panels, magnetic or spotlight feedback for primary controls, and ShinyText-style confidence labels. The interface will avoid cursor-chasing effects, aggressive WebGL canvases, and decorative motion that competes with uncertainty or evidence warnings.

The redesign target is a **tactical ocean signal desk**, not a generic SaaS dashboard. It will use a full-bleed operations canvas, a translucent instrument rail, layered contour/noise texture, a compact command strip, visibly different states for evidence versus interpretation, and animated-but-respectful progression between the five evidence workspaces. Motion will remain under 300ms for frequent actions and will respect reduced-motion preferences.

Sources: [React Bits repository](https://github.com/DavidHDev/react-bits) and [React Bits documentation](https://reactbits.dev/).
