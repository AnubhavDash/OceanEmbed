# OceanEmbed

OceanEmbed is a competition-ready North Indian Ocean decision-support product. It turns approved satellite-surface observations and conservative subsurface reconstruction outputs into traceable heat-fuel evidence. The application is a **reference interface** until an approved data source, a validated model, and cloud credentials are configured.

The dashboard includes operations, OpenCV preprocessing, Argo validation, Agentic Vision QA, and reproducibility views. Run `pnpm check && pnpm test` before changing the decision logic. See [the competition submission pack](docs/COMPETITION_SUBMISSION.md) for architecture, evaluation, setup, responsible-use commitments, and activation requirements.
